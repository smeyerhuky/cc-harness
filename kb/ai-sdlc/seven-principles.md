# Seven Principles of AI-Native Engineering

AI has collapsed the distance between intent and implementation, but speed without discipline leads to unmaintainable technical debt. The AI-SDLC relies on seven core principles:

1. **The developer is responsible**: AI does not own the outcome, the architecture, or the bugs. The developer does.
2. **The spec is the contract**: The spec is not a prompt; it is a shared agreement of what will be built.
3. **Questions are answered in the spec**: Ambiguity must be forced into the open. Answers live in the spec, not in an ephemeral agent chat.
4. **Phases beat marathons**: Code generation must be phased with boundaries for review to maintain legibility.
5. **Verification is part of the work**: Plausible code is not correct code. AI-generated code must be explicitly verified against the spec.
6. **Shared context stays in the repo**: Specs, decisions, and plans belong with the code, readable by humans and AI.
7. **Workflow is centrally managed**: The rules that guide AI development should be versioned infrastructure, not tribal knowledge.
