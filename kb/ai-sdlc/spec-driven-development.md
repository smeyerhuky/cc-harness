# Spec-Driven Development

Spec-Driven Development (SDD) transforms AI-assisted programming from ad-hoc "vibe coding" (unstructured prompting) to disciplined engineering using specifications as "super prompts."

## The Core Technique
* **Specifications over Prompts**: Rather than chatting continuously with an AI, the developer authors a version-controlled specification document. This document acts as the North Star for the agent.
* **The Workflow**: The workflow follows a strict path: `specification → design → implementation`. 
* **Surfacing Ambiguity**: The specification is used to define scope, explicitly exclude out-of-scope items, and surface critical questions. Questions must be answered in the specification itself, not buried in temporary agent chat history.
