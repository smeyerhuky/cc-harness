# Backlog — cc-harness (`CCH`)

Work items for the harness itself: epics, stories, spikes, and tickets, one markdown file each,
`CCH-<KIND>-<NNN>.md`, following the [work-item template](../../pdlc/templates/work-item.md).
Each item's own frontmatter is the source of truth — its `state:`
(what each value means: [an item's life](../../pdlc/work-items.md#an-items-life)), its
`milestone:`, and its `relationships:` (`PART_OF` its epic, `DEPENDS_ON` what it waits for,
`DERIVED_FROM` its source). This page is a view; if it disagrees with an item, the item wins and
this page gets fixed. How items fit into milestones: [roadmap](../roadmap.md).
