# Running Journal — cc-harness

What happened on the harness itself, one entry per working session, **newest first**. Each entry
records what landed (commits, work-item IDs), what broke and why, decisions made with the owner,
and what's next. Entries are appended, never rewritten; the current state lives in
[`handoff.md`](../handoff.md). Each entry follows the
[running-journal entry template](../../pdlc/templates/running-journal-entry.md).

No entries yet. The first session that changes the harness adds the first one at the top of this
list — the [worked example](../../pdlc/worked-example.md) shows one.
