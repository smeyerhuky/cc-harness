# OpenSCAD / FDM Engineering

Knowledge for designing and printing functional parts with OpenSCAD and FDM printers (Bambu Lab, Prusa, etc.). Load only the file that answers your current question.

* [materials.md](materials.md) — FDM material properties: tensile strength, anisotropy, shrinkage, minimum wall thicknesses, clearance tables for PLA/PETG/ABS/Nylon/TPU.
* [mechanics.md](mechanics.md) — Gear module math, pressure angles, bearing fits, shaft–hub joints, snap-fit calculations, stiffness estimates.
* [algorithms.md](algorithms.md) — CSG boolean tree construction, hull/minkowski patterns, B-Rep export strategies, performance optimisation, common anti-patterns.
