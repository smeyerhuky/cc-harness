# Additive Engineering Root

Knowledge base for 3D modelling workflows, parametric design with OpenSCAD, FDM printing, and agentic design-to-print pipelines.

## OpenSCAD / FDM 3D Printing

* [OpenSCAD Platform KB](../platforms/openscad/index.md) — materials, mechanics, and CSG algorithm reference for designing and printing functional parts.

## Skills

The [`scad-design-to-print`](../../.claude/skills/scad-design-to-print/SKILL.md) Claude skill provides an end-to-end workflow for turning a design idea into a verified, printable deliverable. Consult the skill's `references/` folder for:

* `bambu-3mf-spec.md` — generating Bambu-compatible `.3mf` project files.
* `scad-syntax-gotchas.md` — OpenSCAD `use` vs `include`, boolean pitfalls, and export commands.
