# Metamaterials

## Guide

This folder is dedicated to **Metamaterials**. It covers topics including The Adjoint State Method, Triply Periodic Minimal Surfaces (TPMS), Volumetric Additive Manufacturing (VAM).

## Directory Map

* [The Adjoint State Method](adjoint-state-method.md) - Efficiently calculating gradients for topology optimization.
* [Triply Periodic Minimal Surfaces (TPMS)](tpms.md) - Implicit mathematical surfaces with zero mean curvature.
* [Volumetric Additive Manufacturing (VAM)](volumetric-am.md) - Curing 3D objects instantly using tomographic 2D projections.
