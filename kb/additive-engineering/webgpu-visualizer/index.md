# WebGPU Visualizer Architecture

This directory covers modern WebGPU techniques applied to agentic CAD tools. 

- [Basic Rendering pipeline](basic-rendering.md): Setting up a modern WebGPU pipeline for CAD canvas initialization.
- [Picking and Selection](picking-and-selection.md): Hardware-accelerated color coding and raycasting for UI topological mapping.
- [Compute Geometry Kernels](compute-geometry.md): Offloading heavy geometry processing (like prefix sum and sorting) to compute shaders.
