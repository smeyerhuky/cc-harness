# Agentic Architecture

## Guide

This folder is dedicated to **Agentic Architecture**. It covers essential topics such as Multi-Agent Feedback Loops, Geometric Constraint Solvers, The Geometry Kernel, and more.

## Directory Map

* [Multi-Agent Feedback Loops](agent-feedback-loops.md) - How the agent verifies and fixes its own generated CAD.
* [Geometric Constraint Solvers](constraint-solvers.md) - Algorithms that resolve 2D/3D constraints automatically.
* [The Geometry Kernel](geometry-kernel.md) - The deterministic C++ engine that calculates 3D geometry.
* [The Representation Layer (DSL)](representation-layer.md) - How agents write procedural code instead of raw geometry data.
* [The Slicer Agent](slicer-agent.md) - Slicer and agentic printing techniques.
* [UI/UX & Topological Mapping](ui-topological-mapping.md) - Linking user 3D clicks back to the agent's code.
