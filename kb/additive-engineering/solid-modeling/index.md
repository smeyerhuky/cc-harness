# Solid Modeling

## Guide

This folder is dedicated to **Solid Modeling**. It covers essential topics such as Boundary Representation (B-Rep), Constructive Solid Geometry (CSG), Non-Manifold Modeling, and more.

## Directory Map

* [Boundary Representation (B-Rep)](brep.md) - Modeling solids by explicitly storing their bounding topology and geometry.
* [Constructive Solid Geometry (CSG)](csg.md) - Modeling solids through Boolean operations on geometric primitives.
* [Non-Manifold Modeling](non-manifold.md) - Representations that allow topologies breaking the two-manifold constraint.
* [Octrees](octrees.md) - Spatial partitioning data structure recursively dividing 3D space.
