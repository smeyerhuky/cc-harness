# Concepts

Platform-neutral ideas that apply regardless of what you're deploying or where.

* [Deploy Lifecycle](deploy-lifecycle.md) — the abstract flow every deploy follows: scaffold → local-verify → deploy → remote-verify → commit → push.
* [Verification vs Deployment](verification-vs-deployment.md) — "deployed" and "working" are two different claims; know which one you actually have.
* [Progressive Disclosure](progressive-disclosure.md) — how this KB is organized and how to load it incrementally instead of all at once.
