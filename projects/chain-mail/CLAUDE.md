# Chain Mail Configuration

Project-specific Claude configuration and guidelines.

## Structure

- `src/` - Project source code
- `kb/` - Project-specific knowledge base
- `version.json` - Project version metadata
- `README.md` - Project overview

## Development

This project is currently a scaffold created from the playground template. Add project
source to `src/`, document decisions and structure in `kb/`, and keep `version.json`
current as the project evolves.
