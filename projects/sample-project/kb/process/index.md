# Process

How work on this project is planned, tracked, and recorded. The method is the repo's
[PDLC layer](../../../../kb/pdlc/index.md); these files are this project's instances of it.
Cold start: read the handoff first.

* [Handoff](handoff.md) — where the project stands right now, the next step, and a cold-start prompt.
* [Roadmap](roadmap.md) — milestones, each with its todos, exit criterion, and owner check-in.
* [Backlog](backlog/index.md) — `SMP-*` work items; each item's own `state:` is the truth.
* [Running Journal](journal/index.md) — one entry per working session, newest first.
* [Definition of Done](definition-of-done.md) — this project's additions to the repo-wide checklist.
