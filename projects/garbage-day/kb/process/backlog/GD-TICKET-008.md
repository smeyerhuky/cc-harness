# GD-TICKET-008: Port the engine core to TypeScript

## Description

The proof of concept's `Player` class ran hundreds of matches. This item ports it to typed,
DOM-free modules, replacing `Math.pow` gravity with a precomputed 16.16 fixed-point table
([architecture — determinism contract](../../design/architecture.md#determinism-contract)).

## Acceptance Criteria

- `src/engine` exports `PlayerSim` and its supporting modules (rng, bag, pieces and kicks,
  attack, garbage, speed table, power-ups) with no DOM or wall-clock access.
- Unit tests cover every rule and value in `kb/product/game-rules.md`: spawn positions, every
  kick table entry used by a test rotation, lock delay and the 15 resets, the attack table
  including T-spins, back-to-back, combos and perfect clears, cancelling oldest first, the 0.5 s
  ready delay and 8-row cap, one hole per attack from the receiver's stream, the speed table, each
  power-up's effect, and all three top-out conditions.
- The speed table is generated by a script from the formula in `game-rules.md` and checked in; a
  test regenerates it and compares.
- Code gates pass.
