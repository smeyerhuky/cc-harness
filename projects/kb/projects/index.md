## Prefix registry

Every project's work items are `<PREFIX>-<KIND>-<NNN>` (see [work items](../../../kb/pdlc/work-items.md)),
so a prefix must be unique across the repo. **Reserve one here before minting a project's first
work item**, in the same change that registers the project. Every project directory is listed,
including ones without a PDLC layer yet.
